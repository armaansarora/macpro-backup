# Mac Pro Backup site

The public homepage and privacy policy for Mac Pro Backup, a single-user tool that stores encrypted backups of one computer in its owner's Google Drive. Google's OAuth consent screen links to these pages.

**Site:** https://armaansarora.github.io/macpro-backup/

| File | Page |
| --- | --- |
| `index.html` | Homepage |
| `privacy.html` | Privacy policy |

Both are plain HTML with no build step. GitHub Pages publishes them from the root of `main`, so a merged change goes live within a few minutes. To preview locally, open either file in a browser.

The backup tool itself is not in this repository.
